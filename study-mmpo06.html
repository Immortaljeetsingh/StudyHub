Value Analysis Explained

Strategic Importance of Materials Management

Materials management is not just a support function — it's a strategic driver of profitability. In manufacturing, materials typically account for 50-70% of product cost. A 5% reduction in material costs can have the same impact on profit as a 30% increase in sales. This makes materials management one of the most impactful areas for cost optimization.

The strategic role includes: ensuring uninterrupted supply, optimizing inventory levels, building supplier partnerships, driving continuous improvement through value analysis, and supporting new product development. Modern materials management integrates with supply chain management, using technology like ERP systems, RFID tracking, and data analytics for better decision-making.

Value Analysis Methodology

Value Analysis (also called Value Engineering) is a systematic approach to improving the "value" of a product or service by examining its functions. Value = Function / Cost. To increase value, you either improve function or reduce cost.

The value analysis process follows the SAVE framework:

  • Study the function: What does the component do?
  • Analyze alternatives: Can the function be achieved differently?
  • Valuate alternatives: Which alternative provides best value?
  • Execute the change: Implement the improvement
💡 Real-World Example

Boeing makes only ~10% of its aircraft components in-house, outsourcing 90% to focus on design, assembly, and integration (core competencies). Toyota's supplier partnerships reduced defects by 50% through collaborative quality improvement programs.

Economic Order Quantity (EOQ)

EOQ determines the optimal order quantity that minimizes total inventory costs (ordering + holding). It balances the trade-off between frequent small orders (high ordering cost) and infrequent large orders (high holding cost).

📊 EOQ Formula
D = Annual Demand
S = Ordering Cost
H = Holding Cost/Unit/Year

EOQ = √(2 x D x S / H)

📐 EOQ Calculation Example — Mumbai Textile Mill

A Mumbai textile mill uses 10,000 kg of cotton yarn per year. Ordering cost = Rs 2,000 per order. Holding cost = Rs 50 per kg per year.

EOQ = √(2 x 10,000 x 2,000 / 50) = √(8,00,000) = 894 kg

Number of orders per year = 10,000 / 894 = 11.2 orders

Total cost = √(2 x 10,000 x 2,000 x 50) = Rs 44,721

Kanban System Explained

Kanban Types in Detail

  • Production Kanban (P-Kanban) — Authorizes a workstation to produce a specific quantity of a specific part. Signals upstream: "Make X units of part Y."
  • Withdrawal Kanban (W-Kanban) — Authorizes movement of materials from one station to another. Signals: "Move X units from station A to station B."
  • Supplier Kanban — Signals external suppliers to deliver. Used in JIT supply chains.
  • Emergency Kanban — For urgent situations (quality issues, machine breakdown). Temporary, replaces damaged or defective parts.

CONWIP (Constant Work-In-Process)

CONWIP is a hybrid production control system. Like Kanban, it limits WIP, but instead of limiting WIP at each workstation (per-station cards), it limits the total number of cards in the entire system. When a finished product leaves the system, a card is released to authorize a new item entering the system.

  • Advantage over Kanban: Simpler to implement, works better with variable processing times
  • Advantage over Push: Prevents overproduction, reduces WIP buildup
  • Best for: Long production lines, high-variety environments
💡 Real-World Example

Toyota's Kanban system uses physical cards attached to parts bins. When a bin is empty, the card signals upstream to produce more. In India, Tata Motors' Pune plant adopted Kanban in 2015 for its Nexon assembly line, reducing WIP by 40% and lead time by 25%. TVS Motors uses a hybrid Kanban-CONWIP system at its Hosur plant to manage 1,200+ parts across 3 assembly lines.

🧠 Memory Aid

F-D — Push = Forecast, Pull = Demand. CONWIP = "CONstant Work In Process" — system-wide card limit.

✅ Unit 6 Summary

  • Push = forecast-based (MRP); Pull = demand-based (JIT/Kanban)
  • Kanban types: Production, Withdrawal, Supplier, Emergency Kanban
  • CONWIP = hybrid with system-wide WIP limit (not per-station like Kanban)
  • Kanban is visual, simple; CONWIP is better for variable processing times

Unit 7: Work-in-Process (WIP) Inventory

📖 Definition

WIP = partially completed products in the production process. Little's Law = WIP = Throughput x Flow Time. WIP causes: batch processing, waiting times, quality issues.

📊 Little's Law
WIP = Work in Process
Throughput = Output Rate
Flow Time = Start to Finish

WIP = Throughput × Flow Time

📐 Calculation Example

If a factory has 100 units in WIP and produces 20 units/hour, Flow Time = 100/20 = 5 hours.

▶
Little's Law Explained

WIP Reduction Strategies in Detail

  1. Smaller Batch Sizes — Reduce batch from 1000 to 100 units. Less WIP between stations, faster feedback on quality issues.
  2. One-Piece Flow — Move one unit at a time between stations. Eliminates batch waiting time. Toyota's ideal state.
  3. Reduce Setup Times (SMED) — Single-Minute Exchange of Die. Shigeo Shingo's method to change setups in under 10 minutes. Enables smaller batches economically.
  4. Quality at Source (Jidoka) — Stop the line when a defect is found. Prevents defective WIP from accumulating downstream.
  5. Balanced Workstations — Equal cycle times at each station prevent bottlenecks and WIP accumulation.
  6. Drum-Buffer-Rope (DBR) — Theory of Constraints approach. The bottleneck (drum) sets the pace, buffer protects it, rope synchronizes upstream.
💡 Real-World Example

Semiconductor fabs track WIP obsessively — each wafer takes 6-8 weeks through 500+ steps. Reducing WIP by 10% saves millions in working capital. In India, Tata Motors reduced WIP by 35% at its Pune plant by implementing one-piece flow for engine assembly. Bajaj Auto's Chakan plant achieves 4-hour WIP time for motorcycle assembly (vs industry average of 2-3 days).

🧠 Memory Aid

W-T-F — WIP = Throughput × Flow Time. SMED = Single Minute Exchange of Die (setup reduction).

✅ Unit 7 Summary

  • Little's Law: WIP = Throughput x Flow Time (L = λ x W)
  • Derived: Throughput = WIP/Flow Time; Flow Time = WIP/Throughput
  • WIP reduction: smaller batches, one-piece flow, SMED, quality at source, balanced stations
  • WIP causes: batch processing, waiting times, quality issues, unbalanced lines

Vendor Managed Inventory (VMI) in Detail

In VMI, the supplier takes responsibility for managing the buyer's inventory. The supplier monitors stock levels (often through EDI or shared ERP data) and automatically replenishes when levels drop below a threshold.

  • Benefits for buyer: Reduced stockouts (up to 80% reduction), lower administrative costs, freed working capital
  • Benefits for supplier: Better demand visibility, production planning, stronger customer lock-in
  • Requirements: Trust, IT integration, data sharing, clear KPIs

Consignment Stock

In consignment, the supplier owns the inventory physically located at the buyer's premises. The buyer pays only when the stock is consumed. This reduces the buyer's working capital requirement while ensuring supply availability. Unsold stock is returned to the supplier.

💡 Real-World Example

Airlines keep insurance spares (engines, landing gear) at strategic locations worldwide, even though they may rarely be needed. IndiGo Airlines maintains a consignment stock arrangement with Pratt & Whitney for GTF engines at its Delhi and Mumbai hubs, paying only upon use. Tata Steel uses VMI for its Jamshedpur plant — key suppliers like coal vendors monitor consumption via SAP integration and auto-replenish.

  • VMI = supplier monitors and replenishes automatically — reduces stockouts by up to 80%
  • Consignment stock = supplier owns stock at buyer's location, buyer pays on consumption

How to Perform ABC Analysis — Step by Step

  1. List all inventory items with their annual consumption quantity and unit cost
  2. Calculate Annual Usage Value = Quantity x Unit Cost for each item
  3. Rank items from highest to lowest usage value
  4. Calculate cumulative percentage of total value
  5. Classify: Top 80% value = A items, next 15% = B items, bottom 5% = C items

ABC-VED Matrix: Combining ABC (value) with VED (criticality) gives a 9-cell matrix for precise control. For example, an item classified as A-V (high value, vital) gets maximum attention with daily monitoring, while C-D items (low value, desirable) get minimal control.

XYZ Analysis — By Demand Variability

  • X items — Stable, predictable demand (e.g., standard bolts, raw materials). Easy to forecast, suitable for JIT.
  • Y items — Variable but predictable demand with some fluctuation (e.g., seasonal spare parts). Requires safety stock.
  • Z items — Erratic, unpredictable demand (e.g., emergency spares, custom parts). Hard to forecast, need buffer stock.

Codification Types

  • Sequential — Simple numbering: 001, 002, 003. Easy but no information content.
  • Alphanumeric — Category prefix: RM-001 (Raw Material), FG-002 (Finished Goods). Most common in Indian industry.
  • Mnemonic — Memory-based: AL for Aluminium, CU for Copper. Quick recognition.
  • Group Technology — Code by features: shape, material, size. Used in manufacturing (e.g., Opitz coding system).
💡 Real-World Example

A hospital uses VED analysis — vital drugs (epinephrine) are always in stock, essential drugs (antibiotics) are closely monitored, desirable drugs (supplements) have lower priority. AIIMS New Delhi uses ABC-VED matrix to manage 5,000+ drug SKUs, saving Rs 2 crore annually through optimized procurement.

Cycle Counting Best Practices

Cross-Functional Teams in Materials Management

Materials management cannot work in isolation. Cross-functional collaboration ensures alignment:

  • With Finance: Budgeting, payment terms, cash flow management, cost analysis
  • With Quality: Incoming inspection, vendor quality audits, rejection handling

Model Answer Structure: 6 Rs of Materials Management (10 marks)

  1. Introduction (1 mark): Define materials management, importance (50-70% of manufacturing cost)
  2. 6 Rs with explanation (6 marks):
    • Right Material — correct specification, quality standard
    • Right Quantity — economic order quantity, avoid over/under stocking
    • Right Time — just-in-time delivery, avoid production delays
    • Right Place — warehouse location, point of use delivery
    • Right Price — competitive bidding, negotiation, total cost of ownership
    • Right Quality — inspection, vendor quality management, incoming quality control
  3. Real-world example (2 marks): Toyota's JIT system, Amazon's warehouse management
  4. Conclusion (1 mark): Effective materials management reduces costs, improves efficiency

Model Answer Structure: ABC Analysis (10 marks)

  1. Introduction (2 marks): Define ABC analysis, Pareto principle (80/20 rule)
  2. Classification (3 marks):
    • A items: 20% items, 80% value — tight control, frequent review, JIT
    • B items: 30% items, 15% value — moderate control, periodic review
    • C items: 50% items, 5% value — simple controls, bulk ordering
  3. Steps to implement (2 marks): Calculate annual usage value, rank items, classify
  4. Benefits (2 marks): Focus resources on high-value items, reduce inventory costs
  5. Conclusion (1 mark): ABC analysis is foundation of inventory management

Model Answer Structure: Little's Law (10 marks)

  1. Statement (2 marks): L = lambda x W (WIP = Throughput x Flow Time)
  2. Variables explained (3 marks): L (avg items in system), lambda (throughput rate), W (avg time in system)
  3. Derived formulas (2 marks): WIP = Throughput x Flow Time, Flow Time = WIP / Throughput, Throughput = WIP / Flow Time
  4. Numerical example (2 marks): Factory has 100 units WIP, produces 20 units/hour, Flow Time = 100/20 = 5 hours
  5. Applications (1 mark): Manufacturing, healthcare, software development

Model Answer Structure: Push vs Pull Systems (10 marks)

  1. Introduction (2 marks): Define push (forecast-based) and pull (demand-based) production
  2. Comparison table (4 marks): MRP vs JIT/Kanban, forecast vs actual demand, inventory levels, flexibility
  3. Examples (2 marks): Push: traditional manufacturing; Pull: Toyota Production System
  4. Hybrid approach (1 mark): Push-pull decoupling point, lean manufacturing
  5. Conclusion (1 mark): Modern systems combine both approaches

Model Answer Structure: MRP Logic (10 marks)

  1. Introduction (2 marks): Define MRP, purpose (what, when, how much to order)
  2. Inputs (3 marks): MPS (Master Production Schedule), BOM (Bill of Materials), Inventory records
  3. MRP calculations (3 marks): Gross requirements, scheduled receipts, on-hand inventory, net requirements, planned orders
  4. Outputs (1 mark): Planned orders, planned receipts, exception reports
  5. Benefits (1 mark): Reduced inventory, better scheduling, improved customer service

Key Formulas Quick Reference

INVENTORY: Net Requirements = Gross Requirements - Scheduled Receipts - On-hand Inventory Inventory Turnover = COGS / Average Inventory Days of Inventory = 365 / Inventory Turnover Fill Rate = Orders Filled from Stock / Total Orders Stockout Rate = Stockouts / Total Demand LITTLE'S LAW: WIP = Throughput x Flow Time Flow Time = WIP / Throughput Throughput = WIP / Flow Time ECONOMIC ORDER QUANTITY: EOQ = sqrt(2 x D x S / H) where D = annual demand, S = ordering cost, H = holding cost per unit per year REORDER POINT: ROP = (Average Daily Demand x Lead Time) + Safety Stock SAFETY STOCK: SS = Z x sigma x sqrt(LT) where Z = service level factor, sigma = std dev of demand, LT = lead time
