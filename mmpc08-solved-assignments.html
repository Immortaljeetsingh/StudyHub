Q1. What is Information Technology? Explain the major types of information systems used in business.(10 Marks)

Answer: Information Technology is the collection, storage, processing, dissemination, and use of information. IT is not merely hardware and software; it also includes people, processes, and organizational goals, and it enables high-speed computation, fast communication, data storage, process automation, and big data analysis. The five major types of information systems serve different organizational levels. A Transaction Processing System (TPS) handles record keeping and routine reports for clerical staff at the operational level. A Management Information System (MIS) produces routine summaries for middle management at the tactical level. A Decision Support System (DSS) supports complex, semi-structured problem solving by managers. An Executive Information System (EIS) provides trend analysis and drill-down for senior executives, and an Enterprise Resource Planning (ERP) system integrates business processes across the entire organization. Indian examples illustrate the scale: SBI's Core Banking Solution processes over 80 million transactions a day, IRCTC's reservation system checks seat availability across thousands of stations, and TCS manages more than 600,000 employees across 50 countries using integrated systems. The mnemonic TMD-WE, TPS, MIS, DSS, Workflow, ERP, helps recall the types.

Key points:

  • Information Technology is the collection, storage, processing, dissemination, and use of information.

  • IT is not merely hardware and software; it also includes people, processes, and organizational goals, and it enables high-speed computation, fast communication, data storage, process automation, and big data analysis.

Q2. Explain the OSI reference model. How is it different from the TCP/IP model?(10 Marks)

Answer: The OSI reference model is a seven-layer theoretical framework that standardizes network communication. Each layer performs a distinct function: the Application layer (7) provides the user interface with protocols like HTTP, FTP, and SMTP; the Presentation layer (6) handles data formatting and encryption; the Session layer (5) manages sessions; the Transport layer (4) ensures end-to-end delivery using TCP or UDP; the Network layer (3) handles routing and addressing with IP; the Data Link layer (2) frames data using MAC addresses over Ethernet; and the Physical layer (1) transmits raw bits over cables or radio. The order can be recalled as "All People Seem To Need Data Processing." The TCP/IP model, by contrast, has four layers and is the practical implementation used on the Internet: Application (combining OSI layers 5-7), Transport, Internet, and Network Access (combining OSI layers 1-2). The key difference is that OSI is a theoretical reference while TCP/IP is an operational protocol stack. At the transport level, TCP provides reliable, ordered delivery with error checking, while UDP is faster but unreliable, which is why UDP suits streaming and gaming while TCP suits banking and file transfers.

Key points:

  • The OSI reference model is a seven-layer theoretical framework that standardizes network communication.
  • Each layer performs a distinct function: the Application layer (7) provides the user interface with protocols like HTTP, FTP, and SMTP; the Presentation layer (6) handles data formatting and encryption; the Session layer (5) manages sessions; the Transport layer (4) ensures end-to-end delivery using TCP or UDP; the Network layer (3) handles routing and addressing with IP; the Data Link layer (2) frames data using MAC addresses over Ethernet; and the Physical layer (1) transmits raw bits over cables or radio.
  • At the transport level, TCP provides reliable, ordered delivery with error checking, while UDP is faster but unreliable, which is why UDP suits streaming and gaming while TCP suits banking and file transfers.

Q3. What is the DIKW hierarchy? Explain the characteristics of good information.(10 Marks)

Answer: The DIKW hierarchy describes how raw facts are progressively transformed into decision-making capability. Data is raw facts, such as "24500". Information is processed data, "total withdrawals today: Rs 24,500". Knowledge is understanding patterns, "withdrawals spike on weekends". Wisdom is applying that understanding, "stock more cash on Fridays". A bank manager uses exactly this progression to decide daily cash requirements. Good information possesses nine characteristics, remembered by the mnemonic ACER-FRT-SA: Accurate (correct and error-free), Complete (all necessary details present), Economical (worth more than its cost), Reliable (consistent and dependable), Flexible (usable for multiple purposes), Relevant (pertinent to the decision), Timely (available when needed), Simple (easy to understand), and Accessible (available to authorized users). The related principle of GIGO, Garbage In, Garbage Out, warns that processing inaccurate input produces worthless output. Indian practice demonstrates these principles at scale: Tata's Rs 15,000 crore digital transformation and SBI YONO's ten million daily logins depend on information that is accurate, timely, and secure, while India's CERT-In handles over 1.5 million cyber incidents annually, underlining the need for the security dimension of information.

Key points:

  • The DIKW hierarchy describes how raw facts are progressively transformed into decision-making capability.
  • Data is raw facts, such as "24500".
  • Information is processed data, "total withdrawals today: Rs 24,500".

Takeaway: Good information possesses nine characteristics, remembered by the mnemonic ACER-FRT-SA: Accurate (correct and error-free), Complete (all necessary details present), Economical (worth more than its cost), Reliable (consistent and dependable), Flexible (usable for multiple purposes), Relevant (pertinent to the decision), Timely (available when needed), Simple (easy to understand), and Accessible (available to authorized users).

Q4. Write a note on the emerging trends in information technology with Indian examples.(10 Marks)

Answer: The major emerging trends in IT are 5G, the Internet of Things, blockchain, big data, machine learning, and cloud computing, all converging as voice, data, and video merge onto single high-speed IP networks. 5G offers high-speed, low-latency connectivity that powers IoT devices and autonomous vehicles. IoT connects smart devices, such as smart homes and wearables, that operate autonomously. Blockchain is a secure, decentralized distributed ledger used in cryptocurrency and supply chains. Big data is characterized by the six Vs: Volume, Velocity, Variety, Veracity, Value, and Variability. Machine learning comes in three types: supervised (learns from labeled data, as in spam detection), unsupervised (finds patterns in unlabeled data, as in customer segmentation), and reinforcement (learns from rewards and penalties, as in robotics). Cloud computing delivers IaaS, PaaS, and SaaS, like renting a house, a furnished apartment, or a hotel room respectively. India is at the forefront of these trends: UPI processes over ten billion transactions a month, Aadhaar provides identity verification to 1.3 billion people, Jio 5G covers 99% of India, and the Digital India stack of Aadhaar, UPI, DigiLocker, and CoWIN shows how emerging technologies transform governance at national scale.

Key points:

  • The major emerging trends in IT are 5G, the Internet of Things, blockchain, big data, machine learning, and cloud computing, all converging as voice, data, and video merge onto single high-speed IP networks.
  • IoT connects smart devices, such as smart homes and wearables, that operate autonomously.
  • 5G offers high-speed, low-latency connectivity that powers IoT devices and autonomous vehicles.
