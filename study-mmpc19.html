Point 3: Cost of Poor Quality (COPQ)

📖 COPQ Details

Visible costs: Warranty, scrap, rework (only 3-5% of total COPQ)

Hidden costs: Lost customers, reputation damage, employee morale, overtime, expediting

Typical COPQ: 15-25% of sales revenue in most organizations

💡 Real-World Example

Philip Crosby's book "Quality Is Free" (1979) demonstrated that every dollar spent on prevention saves $10 in failure costs.

⚠ Exam Tip

Remember the cost hierarchy: Prevention < Appraisal < Internal Failure < External Failure. A common exam question asks to calculate total quality costs and explain why investing in prevention reduces total costs.

🧠 Memory Aid

"PAIE" — Prevention, Appraisal, Internal, External (cheapest to most expensive)

✅ Unit Summary

  • 4 quality costs: Prevention (lowest) → Appraisal → Internal Failure → External Failure (highest)
  • COPQ = 15-25% of sales revenue
  • Only 3-5% of COPQ is visible; rest is hidden

Point 2: Process Capability Formulas

📖 Key Formulas

Cp = (USL - LSL) / 6σ

Cpk = min[(USL - μ)/3σ, (μ - LSL)/3σ]

Cp ValueInterpretation
Cp < 1.0Process NOT capable
Cp = 1.0Barely capable (3σ)
Cp ≥ 1.33Capable (4σ)
Cp ≥ 1.67Highly capable (5σ)
Cp ≥ 2.0Six Sigma capable

Point 3: Control Charts Details

📖 Control Chart Types
TypeChartPurpose
VariablesX-bar chartCentral tendency
VariablesR chartDispersion (range)
Attributesp chartProportion defective
Attributesc chartNumber of defects

Control Limits: UCL/LCL = Mean ± 3σ

Rule: Points outside control limits = special cause variation → investigate

Point 4: Cpk Interpretation

Cpk ValueInterpretation
Cpk = CpProcess is centered
Cpk < CpProcess is off-center
Cpk ≥ 1.33Centered AND capable

Point 5: Acceptance Sampling

📖 Sampling Risks

Producer's risk (α): Rejecting a good lot (Type I error)

Consumer's risk (β): Accepting a bad lot (Type II error)

💡 Real-World Example

A bottle cap factory measures cap diameter. USL = 26.4mm, LSL = 25.6mm, Mean = 26.0mm, σ = 0.1mm. Cp = (26.4-25.6)/(6×0.1) = 1.33 → Process is capable.

⚠ Exam Tip

Process capability questions are very common. Always calculate both Cp and Cpk — Cp tells you if the process CAN meet specs, Cpk tells you if it IS meeting specs.

🧠 Memory Aid

"CCCHPSF" — Cause-effect, Check sheet, Control chart, Histogram, Pareto, Scatter, Flowchart

✅ Unit Summary

  • 7 QC tools: Cause-effect, Check sheet, Control chart, Histogram, Pareto, Scatter, Flowchart
  • Cp = process capability; Cpk = centering + capability
  • Control charts: Variables (X-bar, R) and Attributes (p, c)
  • Acceptance sampling: Producer's risk vs Consumer's risk

Point 2: ISO 14001 Key Elements

Environmental AspectsLife Cycle PerspectiveEnvironmental PolicyCompliance ObligationsEmergency Preparedness
📖 Key Concepts

Environmental Aspect: Element of activities that interacts with environment (e.g., emissions, waste)

Environmental Impact: Change to environment resulting from an aspect (e.g., air pollution)

Life Cycle Perspective: Considering impacts from cradle to grave (raw materials → disposal)

⚠ Exam Tip

A common exam question compares ISO 9001 and ISO 14001 — both use the same HLS with 10 clauses, but ISO 9001 focuses on customer requirements while ISO 14001 focuses on environmental aspects and regulatory compliance.

💡 Real-World Example

Infosys achieved carbon neutrality using ISO 14001 framework, reducing carbon footprint by 75%.

✅ Unit Summary

  • ISO 14001 = Environmental Management System
  • Same high-level structure as ISO 9001
  • Key elements: Aspects, Life cycle, Policy, Compliance, Emergency
  • Life cycle perspective = cradle to grave

  • IMS reduces duplication and audit costs
