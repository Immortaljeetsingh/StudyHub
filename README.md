# StudyHub

Free IGNOU MBA study material: notes, quizzes, flashcards, and exam resources for all 43 subjects (MMPC, MMPH, MMPB, MMPM, MMPO, MMPF).

## Project Structure

```
StudyHub/
├── index.html              # Redirects to study-hub.html
├── study-hub.html          # Main hub page
├── study-*.html            # Subject notes (43 courses)
├── quiz-*.html             # Quizzes (43 courses)
├── quiz-results.html       # Quiz results page
├── flashcards.html         # Flashcards
├── styles.css              # Global styles
├── app.js                  # Hub page logic
├── api-utils.js            # Shared page utilities
├── quiz-engine.js          # Quiz logic
├── flashcards-app.js       # Flashcards logic
├── sw.js                   # Service worker (PWA offline)
├── manifest.json           # PWA manifest
├── pwa-register.js         # PWA registration
├── scripts/                # Helper scripts
├── seo/                    # SEO generator (generate.js)
├── start-server.bat        # Local server launcher
└── README.md               # This file
```

## Features

- Unit-wise study notes for 43 IGNOU MBA subjects
- Timed quizzes per subject with score tracking
- Flashcards per subject
- Dark/light theme toggle
- PWA support (offline via service worker)
- Solved assignments, guess papers, and study-material landing pages per subject

## Setup

No build step required. Just open `study-hub.html` in a browser.

For PWA/service-worker testing (requires a real origin), run `start-server.bat` or:

```
python -m http.server 8000
```

then visit `http://localhost:8000/study-hub.html`.

## SEO

`sitemap.xml` and `robots.txt` are generated by `seo/generate.js`. The generator also injects meta tags into subject pages, but it overwrites the 172 landing pages in the project root (43 subjects × guess-paper, solved-assignments, study-material, question-paper) and writes `seo/courses.json` — review the diff before running it (see header comment in `seo/generate.js`).
