Unit 1: Concept of Strategy

📖 Strategy — Origin & Definitions

Origin: Greek word Strategos — Stratos (army) + agos (to lead). Originally military, later adapted to business.

Glueck: "Unified, comprehensive and integrated plan relating strategic advantage to environmental challenges."

Chandler (1960): "Determination of basic long-term goals + adoption of courses of action + allocation of resources."

Porter: "Creation of a unique and valued position involving a different set of activities."

📝 Unit 1 Key Summary
  • Strategy = Grand design to achieve objectives using resources
  • Mintzberg's 5Ps: Pattern, Plan, Position, Perspective, Ploy
  • Deliberate = planned & executed; Emergent = evolved naturally
  • Strategy vs Policy: Action-oriented vs Decision-oriented
  • Strategy vs Tactics: Long-term org-wide vs Short-term specific

Unit 2: Strategic Framework

📖 Strategic Intent & Hierarchy

Strategic Intent (Hamel & Prahalad, 1989): Obsessive ambition for success, resource allocation, organizing efforts, motivating people toward goals.

Hierarchy: Vision → Mission → Business Definition → Objectives → Goals

💡 Real-World Example

Amazon's vision: "To be Earth's most customer-centric company" — drives every strategic decision from e-commerce to cloud (AWS) to streaming.

🧠 Memory Aid

"VMODE" — Vision → Mission → Objectives → Definition → Evaluation

📝 Unit 2 Key Summary
  • Strategic Management Process: Intent → Analysis → Formulation → Implementation → Evaluation
  • Vision = Where we want to be | Mission = Why we exist
  • Substantive = what strategy; Procedural = how to implement

PESTLE: Political, Economic, Social, Technological, Legal, Environmental.

EPRG (Perlmutter): Ethnocentric (home), Polycentric (host), Regiocentric (region), Geocentric (global).

Unit 4: External Environment Analysis

📖 External Environment

7 Dimensions: Demographic, Economic, Political/Legal, Sociocultural, Technological, Global, Physical.

I/O Model: External environment determines strategy more than internal resources. Industry structure > firm resources.

▶
External Environment Analysis
▶
I/O vs RBV Model
💡 Real-World Example

COVID-19 pandemic was an external environmental shock that forced companies to restructure strategies (remote work, e-commerce acceleration).

🧠 Memory Aid

"DEPSTG-GP" — Demographic-Economic-Political-Sociocultural-Technological-Global-Geographic-Physical

📝 Unit 4 Key Summary
  • 7 dimensions of general environment
  • I/O Model = outside-in (environment > resources)
  • RBV = inside-out (resources > environment)
  • EFE Matrix = weighted rating of external factors

5 Forces: Threat of New Entrants, Bargaining Power of Suppliers, Bargaining Power of Buyers, Threat of Substitutes, Competitive Rivalry.

🧠 Memory Aid

📝 Unit 5 Key Summary
  • Porter's 5 Forces: New entrants, Suppliers, Buyers, Rivalry, Substitutes
  • Entry barriers: Scale, brand, capital, switching costs, regulation
  • Strategic Groups = clusters of firms with similar strategies
  • CPM = weighted comparison of critical success factors

Unit 6: Internal Analysis

📖 RBV & VRIN Framework

Resource-Based View (RBV): Internal resources and capabilities drive competitive advantage. Inside-out perspective.

VRIN (Barney): Resources must be Valuable, Rare, Inimitable, Non-substitutable.

💡 Real-World Example

Tata Group's core competency = trust and brand reputation built over 150+ years. VRIN? Valuable (customer trust), Rare (few brands have this depth), Inimitable (can't replicate history), Non-substitutable (no shortcut to trust).

🧠 Memory Aid

"VRIN-SWOT" — Valuable-Rare-Inimitable-Non-substitutable + Strengths-Weaknesses-Opportunities-Threats

📝 Unit 6 Key Summary
  • RBV = inside-out perspective (resources drive advantage)
  • VRIN = Valuable, Rare, Inimitable, Non-substitutable
  • Value Chain = Primary + Support activities → Margin
  • SWOT = internal (S/W) + external (O/T) analysis

Unit 7: Business Level Strategies

📖 Porter's Three Generic Strategies

Cost Leadership: Become lowest-cost producer. Differentiation: Offer unique products. Focus: Serve specific niche (cost focus or differentiation focus).

"Stuck in the Middle": Failing to achieve ANY generic strategy = poor performance.

💡 Real-World Example

Air India (pre-Tata) was "stuck in the middle" — neither cost leader (high costs) nor differentiated (poor service). IndiGo chose cost leadership; Vistara chose differentiation.

Unit 10: Strategy Implementation

📖 McKinsey 7S Framework

7S = SSSS-SSS: Strategy, Structure, Systems (Hard) + Style, Staff, Skills, Shared Values (Soft).

Implementation = Action. Strategy without implementation is just a wish.

💡 Real-World Example

When Satya Nadella became Microsoft CEO, he used McKinsey 7S: New Strategy (cloud-first), new Style (growth mindset), new Skills (AI/Cloud), while keeping Structure mostly intact.

🧠 Memory Aid

"7S = SSSS-SSS" — Strategy-Structure-Systems + Style-Staff-Skills + Shared Values

📝 Unit 10 Key Summary
  • McKinsey 7S: 3 Hard + 4 Soft elements
  • Structure types: Functional, Divisional, Matrix, Network
  • Resource allocation must align with strategy

Unit 13: Contemporary Issues in Strategy

📖 Emerging Trends

Digital Strategy: E-commerce, platform businesses, data-driven decisions.

Sustainability: Triple Bottom Line — People, Planet, Profit.

Disruptive Innovation (Christensen): New entrants disrupt incumbents with simpler, cheaper solutions.

Blue Ocean (Kim & Mauborgne): Create uncontested market space.
