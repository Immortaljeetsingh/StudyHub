Unit 1: Operations Management — An Introduction

📖 Core Concepts

Operations Management: Design, operation, and improvement of systems that create and deliver products/services.

Input-Transformation-Output Model: Inputs (materials, labor, capital) > Transformation Process > Outputs (goods, services).

Service Characteristics (I-I-H-P): Intangibility, Inseparability, Heterogeneity, Perishability.

Competitive Priorities (C-Q-F-D): Cost, Quality, Flexibility, Delivery.

📖 Key Definitions

Operations Management: The management of systems or processes that create goods and/or provide services.

Value Added: The difference between the cost of inputs and the value of outputs.

Core Competencies: Unique strengths that provide competitive advantage.

📊 Input-Transformation-Output Model
Inputs (Materials, Labor, Capital)
↓
Transformation Process
↓
Outputs (Goods & Services)
💡 Real-World Example

A restaurant: Inputs (raw food, chefs, kitchen) > Transformation (cooking, plating) > Output (meal served). Service is inseparable (cooked and served simultaneously) and perishable (unsold food is wasted).

🧠 Memory Aid

I-I-H-P = Intangibility, Inseparability, Heterogeneity, Perishability (service characteristics). C-Q-F-D = Cost, Quality, Flexibility, Delivery (competitive priorities).

✅ Unit Summary

  • OM = design + operation + improvement of production/service systems
  • Input-Transformation-Output is the core framework
  • Services have 4 unique characteristics: I-I-H-P
  • 4 competitive priorities: C-Q-F-D

Unit 2: Operations Strategy

📖 Core Concepts

Order Winners: Criteria that win orders from customers (differentiators).

Order Qualifiers: Minimum standards to even be considered in the market.

Strategic Fit: Alignment between competitive strategy and operations capabilities.

Value Chain Analysis: Primary activities (inbound logistics, operations, outbound logistics, marketing & sales, service) + Support activities (HR, technology, procurement, infrastructure).

📖 Key Definitions

Order Winners: Features that differentiate a company's products/services from competitors.

Order Qualifiers: Minimum requirements that customers expect.

💡 Real-World Example

For a budget airline: Low cost is the order winner. Safety is an order qualifier (must have it to be considered, but doesn't win orders).

🧠 Memory Aid

O-W-O-Q = Order Winners win, Order Qualifiers qualify.

✅ Unit Summary

  • Order winners = what wins business; Order qualifiers = minimum to compete
  • Value chain = primary + support activities
  • Strategic fit = aligning ops with business strategy

Unit 3: Sustainable Operations

📖 Core Concepts

Triple Bottom Line (TBL): People, Planet, Profit (3 Ps).

Green Manufacturing: Reducing environmental impact in production.

Circular Economy: Reduce, Reuse, Recycle (eliminate waste concept).

7 Wastes (TIMWOOD): Transport, Inventory, Motion, Waiting, Overproduction, Over-processing, Defects.

📖 Key Definitions

Triple Bottom Line: Measuring success by social, environmental, and financial impact.

Circular Economy: An economic system aimed at eliminating waste through continual use of resources.

Lean: A philosophy that focuses on minimizing waste within a manufacturing system.

💡 Real-World Example

Patagonia uses recycled materials (planet), pays fair wages (people), and remains profitable (profit) — demonstrating TBL in action.

🧠 Memory Aid

P-P-P = People, Planet, Profit (Triple Bottom Line). TIMWOOD = 7 wastes of Lean.

✅ Unit Summary

  • TBL = People + Planet + Profit
  • TIMWOOD = 7 wastes in Lean
  • Circular economy eliminates waste through reuse

Unit 4: Process and Capacity Analysis

📖 Core Concepts

Process Types: Job Shop (low vol, high variety), Batch (medium/medium), Mass/Assembly Line (high vol, low variety), Continuous (very high vol, no variety).

Bottleneck: The process step with the lowest capacity — limits entire system.

Theory of Constraints (TOC): Identify > Exploit > Subordinate > Elevate > Repeat.

Break-Even Analysis: BEP = Fixed Cost / (Price - Variable Cost per unit).

📖 Key Definitions

Bottleneck: The resource with the lowest capacity in the system; it limits overall throughput.

Theory of Constraints: A methodology for identifying and managing bottlenecks.

Break-Even Point: The level of output at which total revenue equals total cost.

💡 Real-World Example

In a pizza shop: dough prep (20/hr) > baking (12/hr) > packaging (25/hr). Baking is the bottleneck at 12/hr. TOC says: exploit (maximize oven use), then subordinate (slow down prep to match baking).

🧠 Memory Aid

TOC = I-E-S-E-R = Identify, Exploit, Subordinate, Elevate, Repeat.

💰 Key Formula: BEP = FC / (P - VC)

✅ Unit Summary

  • 4 process types: Job Shop, Batch, Mass, Continuous
  • Bottleneck = lowest capacity step
  • TOC: Identify → Exploit → Subordinate → Elevate → Repeat
  • BEP = FC / (P - VC)

Unit 5: Facility Layout

📖 Core Concepts

Layout Types: Product (high vol, standardized), Process (low vol, high variety), Cellular (group similar machines), Fixed-Position (large, immovable products).

Line Balancing: Distributing work evenly across workstations.

Cycle Time = Available Time / Required Output.

Min Stations = Sum of Task Times / Cycle Time.

Efficiency = Sum of Task Times / (Number of Stations x Cycle Time).

📖 Key Definitions

Line Balancing: Assigning tasks to workstations so that each has approximately equal time.

Cycle Time: The maximum time allowed at each workstation.

💡 Real-World Example

Car assembly line (product layout) vs hospital (process layout — each department is a different process). Cell phone manufacturing uses cellular layout — grouped by product family.

🧠 Memory Aid

P-P-C-F = Product, Process, Cellular, Fixed-position layouts.

💰 Key Formulas: Cycle Time = Available Time / Required Output | Min Stations = Task Times / Cycle Time | Efficiency = Task Times / (Stations x Cycle Time)

✅ Unit Summary

  • 4 layout types: Product, Process, Cellular, Fixed-Position
  • Cycle time determines workstation pace
  • Line balancing distributes work evenly

Unit 6: Product and Service Design

📖 Core Concepts

QFD (Quality Function Deployment): Translates customer needs (WHATs) into technical requirements (HOWs) — "House of Quality".

DFM (Design for Manufacturing): Design products for easy manufacturing.

DFA (Design for Assembly): Reduce number of assembly steps.

Modular Design: Use standardized, interchangeable modules.

Concurrent Engineering: Parallel design activities (faster time-to-market).

📖 Key Definitions

QFD: A method to transform user demands into design quality and deploy the quality into components.

Concurrent Engineering: Simultaneous performance of product design and process design.

💡 Real-World Example

IKEA uses modular design — standardized components that can be combined in different ways. Assembly instructions are designed for customers (DFA).

🧠 Memory Aid

Q-D-M-C = QFD, DFM/DFA, Modular, Concurrent.

✅ Unit Summary

  • QFD = House of Quality (customer needs → technical specs)
  • DFM = easy to make; DFA = easy to assemble
  • Modular design enables flexibility
  • Concurrent engineering = parallel design

Unit 7: Demand Forecasting

📖 Core Concepts

Qualitative Methods: Delphi method, Market Survey, Expert Opinion (subjective).

Quantitative — Time Series: Moving Average, Exponential Smoothing, Trend Analysis.

Quantitative — Causal: Regression, Correlation.

Exponential Smoothing: F(t+1) = alpha x D(t) + (1-alpha) x F(t). Higher alpha = more responsive.

Error Measures: MAD (Mean Absolute Deviation), MSE (Mean Squared Error), MAPE (Mean Absolute Percentage Error).

📖 Key Definitions

Exponential Smoothing: A weighted moving average where recent data gets more weight.

MAD: Average of absolute forecast errors.

MAPE: Average of absolute percentage errors (best for comparing across datasets).

💡 Real-World Example

A retailer uses exponential smoothing (alpha = 0.3). If actual = 100 and forecast = 90, new forecast = 0.3(100) + 0.7(90) = 93.

🧠 Memory Aid

alpha-D + (1-alpha)-F = Exponential smoothing formula.

💰 Key Formulas: F(t+1) = aD(t) + (1-a)F(t) | MAD = Σ|A-F|/n | MAPE = Σ|Error/A|/n × 100

✅ Unit Summary

  • Qualitative: Delphi, surveys, expert opinion
  • Quantitative: Time series (moving avg, exp smoothing) + Causal (regression)
  • Exponential smoothing: recent data weighted more
  • MAD, MSE, MAPE = error measures

Unit 8: Inventory Management

📖 Core Concepts

Inventory Types: Raw Materials, WIP, Finished Goods, MRO.

ABC Analysis: A items (80% value, 20% items), B items (15% value, 30% items), C items (5% value, 50% items).

EOQ = sqrt(2DS/H). D = annual demand, S = ordering cost, H = holding cost.

ROP = d x L + Safety Stock. d = daily demand, L = lead time.

Safety Stock = Z x sigma x sqrt(L).

JIT: Produce only what's needed, when needed, in the quantity needed.

Kanban: Pull system using visual signals (cards).

📖 Key Definitions

EOQ: The order quantity that minimizes total inventory costs (ordering + holding).

Safety Stock: Extra inventory held to buffer against demand/supply variability.

JIT: An inventory strategy that increases efficiency by receiving goods only as needed.

💡 Real-World Example

Amazon uses ABC analysis: A items (high-value electronics) in easily accessible locations. C items (cheap accessories) in back storage.

🧠 Memory Aid

EOQ = sqrt(2DS/H). A = 80/20 rule = ABC Analysis.

💰 Key Formulas: EOQ = sqrt(2DS/H) | ROP = d×L + SS | SS = Z×sigma×sqrt(L)

✅ Unit Summary

  • ABC: A=80/20, B=15/30, C=5/50
  • EOQ minimizes ordering + holding costs
  • ROP = when to reorder; Safety Stock = buffer
  • JIT = only what's needed, when needed

Unit 9: Aggregate Planning

📖 Core Concepts

Aggregate Plan: Medium-term production plan (3-18 months) that determines output levels.

Chase Strategy: Match demand by adjusting workforce (hire/fire as needed).

Level Strategy: Constant production rate, use inventory/backlog to absorb demand fluctuations.

Mixed Strategy: Combination of chase and level.

Costs: Regular time, Overtime, Hiring, Firing, Inventory holding, Backorder.

📖 Key Definitions

Aggregate Planning: A process to develop a preliminary, approximate schedule of the overall operations.

Chase Strategy: Adjusting capacity to match demand (variable workforce).

Level Strategy: Maintaining constant capacity regardless of demand.

💡 Real-World Example

An ice cream factory uses chase strategy (more workers in summer, fewer in winter). A paper mill uses level strategy (constant production, build inventory in low-demand periods).

🧠 Memory Aid

C-L-M = Chase, Level, Mixed strategies.

✅ Unit Summary

  • Chase = adjust workforce to match demand
  • Level = constant production, use inventory
  • Mixed = combination approach

Unit 10: Materials Requirement Planning (MRP)

📖 Core Concepts

MRP Inputs: Master Production Schedule (MPS), Bill of Materials (BOM), Inventory Records.

MRP Logic: Gross Requirements > Scheduled Receipts > Net Requirements > Planned Order Releases.

Lot Sizing: EOQ, Lot-for-Lot, POQ (Period Order Quantity).

MRP II: Manufacturing Resource Planning (adds capacity planning to MRP).

ERP: Enterprise Resource Planning (integrates all business functions).

📖 Key Definitions

MRP: A system for calculating the materials and components needed to manufacture a product.

ERP: An integrated system that manages core business processes in real-time.

BOM: A hierarchical list of all components needed to make a product.

💡 Real-World Example

A car manufacturer's BOM: Car > Engine (pistons, crankshaft, cylinders), Body (doors, hood, frame), Interior (seats, dashboard, carpet).

🧠 Memory Aid

M-B-I = MRP inputs: MPS, BOM, Inventory Records.

✅ Unit Summary

  • MRP inputs: MPS, BOM, Inventory Records
  • MRP logic: Gross → Net → Planned Orders
  • ERP = MRP + finance + HR + everything

Unit 11: Scheduling and Sequencing

📖 Core Concepts

FCFS: First Come First Served — simple, fair.

SPT: Shortest Processing Time — minimizes average flow time.

EDD: Earliest Due Date — minimizes maximum lateness.

CR: Critical Ratio = (Due Date - Today) / Processing Time.

Johnson's Rule: For 2-machine flow shop sequencing.

Flow Time: Total time a job spends in the system. Makespan: Total time to complete all jobs.

📖 Key Definitions

SPT Rule: Process the job with the shortest processing time first.

Johnson's Rule: An algorithm for optimally sequencing jobs through two machines.

Flow Time: Time from job arrival to completion.

💡 Real-World Example

A mechanic with 3 cars: Oil change (30 min), Brake repair (2 hrs), Tire rotation (45 min). SPT sequence: Oil (30) > Tire (45) > Brake (120). Minimizes average waiting time.

🧠 Memory Aid

SPT = Shortest First = Min Flow Time. EDD = Earliest Due = Min Lateness.

✅ Unit Summary

  • FCFS = fair; SPT = min flow time; EDD = min lateness
  • Johnson's Rule for 2-machine sequencing
  • Gantt charts visualize schedules

Unit 12: Six Sigma Quality Control

📖 Core Concepts

SQC: Monitor and control process quality using statistics.

Variables vs Attributes: Measurable (length, weight) vs Countable (defects, defectives).

Control Charts: X-bar and R charts (variables), p-chart and c-chart (attributes).

7 QC Tools: Flowchart, Check Sheet, Histogram, Scatter Diagram, Control Chart, Fishbone (Ishikawa), Pareto Chart.

Six Sigma: 3.4 defects per million opportunities (DPMO).

DMAIC: Define > Measure > Analyze > Improve > Control (existing processes).

DMADV: Define > Measure > Analyze > Design > Verify (new processes).

Cp = (USL - LSL) / 6sigma. Cpk = min[(USL - mu)/3sigma, (mu - LSL)/3sigma].

📖 Key Definitions

Six Sigma: A methodology that aims for near-perfect quality (3.4 DPMO).

DMAIC: The structured problem-solving methodology of Six Sigma.

Control Chart: A statistical tool to monitor process variation over time.

Cp: Process capability ratio (potential capability). Cpk: Process capability index (actual, accounts for centering).

💡 Real-World Example

A hospital tracks patient wait times using X-bar charts. If a point falls outside UCL, the process is out of control and needs investigation.

🧠 Memory Aid

DMAIC = Define, Measure, Analyze, Improve, Control. DPMO = 3.4 at Six Sigma.

💰 Key Formulas: Cp = (USL-LSL)/6σ | Cpk = min[(USL-μ)/3σ, (μ-LSL)/3σ] | UCL = X̄ + A₂R̄

✅ Unit Summary

  • Six Sigma = 3.4 DPMO
  • DMAIC for existing; DMADV for new processes
  • 7 QC tools: Flowchart, Check Sheet, Histogram, Scatter, Control Chart, Fishbone, Pareto
  • Cp = can it fit? Cpk = is it centered?

Unit 13: Total Quality Management (TQM)

📖 Core Concepts

TQM: Organization-wide approach to continuous quality improvement.

Deming's 14 Points: Management philosophy for quality.

PDCA Cycle: Plan > Do > Check > Act (continuous improvement loop).

Kaizen: Continuous, incremental improvement (Japanese philosophy).

5S: Sort (Seiri), Set in Order (Seiton), Shine (Seiso), Standardize (Seiketsu), Sustain (Shitsuke).

Poka-Yoke: Error-proofing (design processes to prevent mistakes).

Quality Costs: Prevention, Appraisal, Internal Failure, External Failure.

📖 Key Definitions

TQM: A management approach focused on long-term success through customer satisfaction.

Kaizen: Continuous improvement through small, incremental changes.

5S: A workplace organization method.

Poka-Yoke: Error-proofing mechanisms that prevent defects.

💡 Real-World Example

Toyota uses 5S in factories: Sort (remove unnecessary tools), Set (organize by frequency of use), Shine (clean daily), Standardize (checklists), Sustain (audits).

🧠 Memory Aid

S-S-S-S-S = Sort, Set, Shine, Standardize, Sustain (5S). PAIF = Prevention, Appraisal, Internal Failure, External Failure (quality costs).

✅ Unit Summary

  • TQM = organization-wide quality improvement
  • PDCA = Plan-Do-Check-Act cycle
  • Kaizen = continuous small improvements
  • 5S = Sort, Set, Shine, Standardize, Sustain
  • Poka-Yoke = error-proofing

Unit 14: Maintenance Management

📖 Core Concepts

Maintenance Types: Breakdown (reactive), Preventive (scheduled), Predictive (condition-based), TPM (operators maintain own equipment).

OEE = Availability x Performance x Quality.

Availability = Uptime / Planned Production Time. Performance = Actual Output / Max Possible. Quality = Good Units / Total Units.

MTBF = Mean Time Between Failures (reliability). MTTR = Mean Time To Repair (maintainability).

Availability = MTBF / (MTBF + MTTR).

📖 Key Definitions

TPM: A system where operators are responsible for maintaining their own equipment.

OEE: A measure of how well a manufacturing operation is utilized.

MTBF: Average time between equipment failures.

MTTR: Average time to repair equipment after failure.

💡 Real-World Example

A factory's OEE = 90% Availability x 95% Performance x 99% Quality = 84.6%. World-class OEE is 85%+.

🧠 Memory Aid

A x P x Q = OEE formula. MTBF/(MTBF+MTTR) = Availability.

💰 Key Formulas: OEE = A × P × Q | Availability = MTBF/(MTBF+MTTR)

✅ Unit Summary

  • 4 maintenance types: Breakdown, Preventive, Predictive, TPM
  • OEE = Availability × Performance × Quality (world class = 85%+)
  • MTBF = reliability; MTTR = maintainability
  • Availability = MTBF/(MTBF+MTTR)
