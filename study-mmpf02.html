Unit 1: Nature of Long-Term Financial Decisions

📖 Definition

Investment Decision: Deciding the total amount of assets, their composition, and the business risk of the firm. The most important financial decision.

Financing Decision: Determining the optimal mix of debt and equity to maximize firm value.

NPV Rule: Accept a project if NPV > 0. NPV links investment and financing decisions through the discount rate (cost of capital).

📊 Three Financial Decisions (IFD)
Investment Decision (MOST IMPORTANT)
↓
Financing Decision (Debt vs Equity)
↓
Dividend Decision (Distribute vs Retain)
💡 Real-World Example

When Reliance Jio invested Rs 1.5 lakh crore in telecom infrastructure (investment decision), it funded through a mix of internal accruals, debt, and equity (financing decision).

🧠 Memory Aid

IFD = Investment, Financing, Dividend (3 financial decisions)

✅ Unit Summary

  • Three financial decisions: Investment (most important), Financing, Dividend
  • NPV links investment and financing decisions through discount rate
  • Time Value of Money: Rs 100 today > Rs 100 tomorrow

Unit 2: Cost of Capital

📖 Definition

WACC (Weighted Average Cost of Capital): The average rate of return required by all investors, weighted by their proportion in the capital structure.

Cost of Equity: Ke = Rf + Beta x (Rm - Rf) or Ke = D1/P0 + g

Cost of Debt: Kd = Interest rate x (1 - tax rate) [tax shield benefit]

📊 WACC Formula
WACC = (E/V x Ke) + (D/V x Kd x (1-t))
↓
Debt is Cheaper (Tax Shield on Interest)
💡 Real-World Example

Infosys has low WACC due to zero debt (mostly equity-funded), while Bharti Airtel has higher WACC due to debt costs.

🧠 Memory Aid

WACC = EKe + DKd(1-t) = Weighted Average Cost of Capital formula

✅ Unit Summary

  • Component costs: Ke (CAPM/DGM), Kd (tax-adjusted), Kp (dividend/price)
  • Debt cheaper than equity due to tax shield
  • WACC calculation is very common numerical problem

Financial Leverage: DFL = EBIT / (EBIT - Interest). Magnifies EPS changes.

Operating Leverage: DOL = % change in EBIT / % change in Sales. Magnifies EBIT changes.

Tata Motors uses high financial leverage (large debt) to amplify equity returns during good times, but this amplifies losses during downturns.

Project Life Cycle: Conception → Planning → Execution → Termination

Conception (Feasibility Study)
↓
Planning (Design, Budgeting)
↓
Execution (Construction)
↓

Building a new factory involves conception (feasibility study), planning (design, budgeting), execution (construction), and termination (commissioning).

CPET = Conception, Planning, Execution, Termination

Unit 5: Capital Budgeting — Investment Appraisal

📖 Definition

NPV: Sum of [CFt / (1+r)^t] - Investment. Accept if NPV > 0. Best method.

IRR: Discount rate where NPV = 0. Accept if IRR > Cost of Capital.

PI: PV of Inflows / PV of Outflows. Accept if PI > 1.

MethodTVM?Decision RuleWeakness
PaybackNoShorter = BetterIgnores TVM
ARRNoHigher = BetterIgnores TVM
NPVYesNPV > 0 = AcceptNeeds accurate r
IRRYesIRR > r = AcceptMultiple IRRs possible
PIYesPI > 1 = AcceptConflicts with NPV
💡 Real-World Example

If a project costs Rs 100,000 and generates Rs 30,000/year for 5 years at 10%: NPV = 30,000 x 3.791 - 100,000 = Rs 13,730 (Accept). PI = 113,730/100,000 = 1.137 (Accept).

🧠 Memory Aid

PIRR-N = Payback, IRR, ARR, NPV, PI and "NPV is King"

✅ Unit Summary

  • Non-discounted: Payback Period, ARR
  • Discounted: NPV (best), IRR, PI
  • NPV > 0 = Accept; IRR > r = Accept; PI > 1 = Accept

Unit 6: Project Implementation and Control (PERT/CPM)

📖 Definition

Critical Path: The longest sequence of activities determining minimum project duration. Zero float.

PERT: Uses 3 time estimates. Expected time = (O + 4M + P) / 6. Variance = [(P-O)/6]^2

📊 PERT vs CPM
PERT: 3 estimates (O, M, P) — Probabilistic
↓
CPM: Single estimate — Deterministic
💡 Real-World Example

In construction, if foundation laying is on the critical path, any delay directly delays the entire project.

🧠 Memory Aid

O-M-P = Optimistic, Most likely, Pessimistic (PERT time estimates)

✅ Unit Summary

  • PERT: 3 estimates, probabilistic; CPM: single estimate, deterministic
  • Critical path = longest path = minimum project duration
  • PERT time = (O + 4M + P) / 6

Unit 7: Social Cost Benefit Analysis (SCBA)

📖 Definition

Shadow Prices: Prices reflecting true social value (may differ from market prices).

SCBA: Evaluates projects considering social costs and benefits, not just financial returns.

💡 Real-World Example

A highway project may have negative NPV financially but positive social NPV when considering reduced travel time, lower pollution, and economic development.

🧠 Memory Aid

SCBA = Society First, Profit Second

✅ Unit Summary

  • SCBA for public sector and infrastructure projects
  • Shadow prices reflect true social value
  • UNIDO vs Little-Mirrlees approaches

Unit 8: Investment Decisions — CAPM & Risk

📖 Definition

CAPM: E(R) = Rf + Beta x (Rm - Rf). Describes relationship between systematic risk and expected return.

Beta: Measure of systematic risk. Beta = 1 (same as market), Beta > 1 (aggressive), Beta < 1 (defensive).

📊 CAPM Model
E(R) = Rf + Beta x (Rm - Rf)
↓
Systematic Risk (Market) vs Unsystematic Risk (Company)
💡 Real-World Example

If Rf = 7%, Beta = 1.2, Rm = 15%: Expected Return = 7% + 1.2 x (15% - 7%) = 7% + 9.6% = 16.6%

🧠 Memory Aid

CAPM = Rf + B(Rm-Rf) and B>1 = More Risk, B<1 = Less Risk

✅ Unit Summary

  • CAPM: E(R) = Rf + Beta(Rm - Rf)
  • Systematic risk (market, can't diversify) vs Unsystematic (company-specific, can diversify)
  • Beta interpretation: 1 = market, >1 = aggressive, <1 = defensive

Unit 9: Project Evaluation Under Risk

📖 Definition

Sensitivity Analysis: Tests how output changes when one input variable changes ("What if" analysis).

Monte Carlo Simulation: Random sampling from probability distributions to model uncertainty.

💡 Real-World Example

For a new product launch, sensitivity analysis might show that NPV is most sensitive to selling price and least sensitive to administrative costs.

🧠 Memory Aid

SSMD = Sensitivity, Scenario, Monte Carlo, Decision trees (risk analysis techniques)

✅ Unit Summary

  • Sensitivity: "What if" one variable changes
  • Scenario: Best, worst, most likely
  • Monte Carlo: Random sampling simulation
  • RADR: Higher discount rate for riskier projects

Unit 10: Financing Through Domestic Capital Markets

📖 Definition

Primary Market: New securities issued (IPO, FPO, Rights). Companies raise capital directly.

Secondary Market: Existing securities traded (BSE, NSE). Companies don't receive funds.

FeaturePrimary MarketSecondary Market
SecuritiesNew issuesExisting securities
IssuerCompany directlyInvestors trade
PriceFixed/book-builtMarket determined
PurposeCapital raisingLiquidity
ExampleIPOBSE/NSE trading
💡 Real-World Example

Zomato's IPO in 2021 raised Rs 9,375 crore from the primary market. After listing, shares trade on BSE/NSE in the secondary market.

🧠 Memory Aid

Primary = New, Secondary = Old and IFR = IPO, FPO, Rights issue

✅ Unit Summary

  • Money market (short-term) vs Capital market (long-term)
  • Primary: IPO, FPO, Rights issue
  • Secondary: BSE, NSE trading

Unit 11: Financing Through Global Capital Markets

📖 Definition

GDR: Listed on European stock exchanges. ADR: Listed on US exchanges (NYSE, NASDAQ).

ECB: External Commercial Borrowings from foreign sources. FCCB: Foreign Currency Convertible Bonds.

💡 Real-World Example

Infosys has ADRs listed on NYSE, allowing US investors to invest in the Indian company through the American market.

🧠 Memory Aid

GDR = Global, ADR = American and ECB = External Commercial Borrowings

✅ Unit Summary

  • GDR = Europe, ADR = America
  • ECB = External borrowings, FCCB = Convertible bonds
  • Benefits: Larger capital pools, lower cost, global visibility

Unit 12: Other Modes of Financing

📖 Definition

Finance Lease: Long-term, non-cancellable, lessee bears all risks. Essentially a financing arrangement.

Securitization: Converting illiquid assets (loans, receivables) into tradeable securities.

FeatureOperating LeaseFinance Lease
DurationShort-termLong-term (full economic life)
CancellableYesNo
MaintenanceLessorLessee
RiskLessor bearsLessee bears
AccountingOff-balance sheetOn-balance sheet
💡 Real-World Example

Flipkart received venture capital funding from Tiger Global, Accel Partners, and others before its acquisition by Walmart.

🧠 Memory Aid

OLHV = Operating Lease, Hire purchase, Venture capital (financing modes)

✅ Unit Summary

  • Leasing: Operating (short-term) vs Finance (long-term)
  • Venture capital for startups/high-growth companies
  • Securitization: Convert loans into tradeable securities

Unit 13: Capital Restructuring (M&A)

📖 Definition

Horizontal Merger: Same industry (e.g., Vodafone + Idea). Vertical: Different stages of supply chain. Conglomerate: Unrelated businesses.

LBO: Leveraged Buyout — Acquisition using primarily borrowed funds.

💡 Real-World Example

Vodafone-Idea merger (2018) was a horizontal merger to combat Jio's competitive threat. The merged entity became India's largest telecom operator.

🧠 Memory Aid

HVC = Horizontal, Vertical, Conglomerate (merger types)

✅ Unit Summary

  • Merger types: Horizontal, Vertical, Conglomerate
  • M&A motives: Synergy, growth, diversification, tax benefits
  • LBO = acquisition with borrowed funds

Unit 14: Financial Engineering

📖 Definition

Derivatives: Financial instruments whose value is derived from underlying assets. Types: Futures (obligation), Options (right), Swaps (exchange of cash flows).

💡 Real-World Example

Indian companies use interest rate swaps to convert floating-rate debt to fixed-rate, managing interest rate risk.

🧠 Memory Aid

FOS = Futures, Options, Swaps (derivative types)

✅ Unit Summary

  • Derivatives: Futures (obligation), Options (right), Swaps (exchange)
  • Securitization: Creating tradeable securities from asset pools
  • Structured products: Customized investment combinations

Unit 15: Investor Relations

📖 Definition

Corporate Governance: System of rules by which a company is directed, ensuring accountability to all stakeholders.

Insider Trading: Buying/selling securities based on material, non-public information. Illegal under SEBI.

💡 Real-World Example

Infosys is known for best-in-class corporate governance practices — high transparency, independent board, regular disclosures — which attracts global investors.

🧠 Memory Aid

DCIG = Disclosure, Corporate governance, Insider trading, Governance codes

✅ Unit Summary

  • SEBI regulations for disclosure and transparency
  • Insider trading = illegal use of non-public information
  • Corporate governance: Board responsibilities, independent directors, audit committees
